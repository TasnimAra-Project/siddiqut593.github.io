Text Mining & Statistical Analysis R · tidytext · ggplot2 · Quarto

Are Horoscopes Just Vague Nonsense? A Text Mining Analysis

A data-driven challenge to astrology. I analyzed 21,959 daily horoscope predictions across all 12 zodiac signs to test whether horoscopes are genuinely personalized or statistically identical no matter your sign.

Methods Used

  • Regular expressions to extract planetary mentions and hedge phrases, testing astrology's core claim that ruling planets shape daily predictions
  • Tokenization with custom stopword filtering to identify the most common vocabulary across signs
  • Sentiment analysis using the AFINN lexicon to measure emotional tone by sign and month
  • TF-IDF to identify words that are uniquely distinctive to each zodiac sign

Key Findings

  • Sentiment scores clustered between 1.15 and 1.30 on a −5 to +5 scale statistically near-identical across all 12 signs
  • 99% of all entries scored positive regardless of sign
  • The most uniquely "Scorpio" word in Scorpio horoscopes was "Scorpio" itself
  • Average ruling planet mention rate (8.1%) fell below the 10% random baseline
Key Insight: Horoscopes share near-identical sentiment, vocabulary, and planetary language regardless of which zodiac sign they target.

Visualizations

A heatmap of sentiment by sign and month, and a ridgeline density plot of daily sentiment scores per sign, both revealing how uniform the emotional language is across the zodiac.

Transferable Skills: Text mining and NLP techniques to turn unstructured language into quantitative, testable claims, directly applicable to customer feedback and brand voice research.

Dollars & Dynasties: A Data Analysis of the World's Billionaires

Nearly two decades of extreme wealth, unpacked. I built a relational database exploring Forbes billionaire data from 1996–2014, asking: Does GDP predict billionaire output? Are billionaires more likely self-made or inherited? Which industries create the most wealth?

Database Design & SQL Engineering

Multi-table relational schema in DuckDB via R, with 8 SQL queries using window functions (RANK, LAG, PARTITION BY), joins, CASE statements, and HAVING clauses.

4 Publication-Quality Visualizations

  • Mollweide choropleth world map of billionaire concentration
  • Lollipop chart comparing self-made vs inherited wealth by region
  • Dual-encoded bar chart of top wealth-generating industries
  • Log-log scatter plot of GDP to billionaire relationship with ggrepel labels

Key Findings

  • The US produced nearly 6× more billionaires than any other country
  • Technology created the wealthiest individuals despite lower headcount
  • Singapore and Switzerland dramatically underproduced billionaires relative to GDP
Key Insight: GDP alone is a poor predictor of billionaire output: institutional factors, industry mix, and tax policy matter far more.
Transferable Skills: End-to-end data pipeline skills from schema design and SQL querying to polished, publication-ready visual communication.

finclean: R Package for Financial Data Cleaning & Diagnostics

Professional software, built from scratch. finclean is an R package I developed in an advanced data computing course to help analysts clean, audit, and visualize messy financial datasets following industry-standard practices including full documentation, unit testing, and defensive programming.

Six Core Functions

  • parse_currency() : converts strings like "$1,234.56" or "(1,200)" into clean numeric values
  • standardize_fiscal_year() : normalizes "FY23", "Q1 2023", "2023-Q2" into one consistent format
  • normalize_accounts() : maps "Rev." and "REVENUE" to standardized labels
  • flag_outliers() : detects suspicious values via IQR or z-score method
  • audit_report() : structured summary of missing values, duplicates, and outliers
  • plot_outliers() : bar chart highlighting flagged observations in red

Software Engineering Standards

  • 40+ unit tests using the testthat framework
  • Input validation with checkmate and full roxygen2 documentation
  • Long-form vignette walking through a realistic financial data cleaning workflow
Key Achievement: Built and shipped a fully documented, tested, publicly hosted R package, the same workflow used by professional CRAN authors.

Documentation & Deployment

Professional pkgdown documentation site hosted on GitHub Pages, with built-in sample dataset and complete function reference.

Deal Activity Prediction: From Unsupervised to GPT-Enhanced ML

My biggest challenge yet: Predicting deal closure probability from an unlabeled dataset of wealth management activities, pushing me to innovate with GPT-4 labeling and advanced ML techniques.

Two-Pronged Approach

Phase 1: Unsupervised: KMeans (29.8%) and Agglomerative Clustering (34.2%) — traditional methods couldn't capture nuanced deal patterns.

Phase 2: GPT-4 Enhanced: Flattened nested JSON → GPT-4 labeling (High/Medium/Low) → feature engineering → Random Forest vs XGBoost with SMOTE balancing.

Key Breakthrough: GPT-4 labeling captured business context pure statistics missed → 97% accuracy improvement (34% → 67%).

Results

  • XGBoost: 67% accuracy (vs 34% unsupervised baseline)
  • Random Forest: 64% with better medium-class recall
  • Top predictors: Email activity ratios and engagement density
Innovation Skills: Combining cutting-edge AI (GPT-4) with traditional ML to solve problems where labeled data doesn't exist.

Image Processing & Video Production

Creative R: Automated Image Editing & Video Pipeline with magick & av

A project that pushed R beyond data analysis — into image processing, cinematic color grading, and fully automated video production.

What I Built

  • Image Processing (magick): Applied rotation, brightness/saturation tuning, color tinting, contrast enhancement, and letterbox formatting to landscape photos from Pictured Rocks National Lakeshore — entirely in R, no external software
  • Automated Video Pipeline (av): Compiled still images and live footage into a short narrative "day in the life" cat video, with each scene resized to a consistent 720×1280 portrait frame and annotated with time-of-day labels
  • Dynamic Text Overlays: Applied conditional captions at precise timestamps (e.g. triggering mid-clip at the 6-second mark) using frame-level compositing
  • Final Output: All frames encoded into a clean H.264 MP4 via av_encode_video() — end-to-end from raw assets with no manual editing
Key Insight: R is a surprisingly powerful creative tool. This project demonstrated that reproducible, programmatic workflows can replace manual editing pipelines entirely.
